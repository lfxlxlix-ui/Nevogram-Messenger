# Nevogram Native for Android

This directory is the start of the native Android client (Kotlin + Android SDK). It is intentionally separate from the existing web client.

## Backend
The native client will use the existing HTTPS API at https://nevogram-messenger.onrender.com. Existing accounts and messages remain on the server.

## Build
The Android project and CI build workflow will be added in follow-up commits. This scaffold is not yet a complete or installable app.
